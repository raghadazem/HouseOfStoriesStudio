# Characters

One subfolder per main character, e.g. `melissa/`, `bilsan/`. Each
character folder holds:

```
<character_id>/
├── character_meta.yaml   # Character Lock record (see app/core/templates/character/)
├── reference/            # APPROVED canon artwork only — current version
└── versions/              # historical/superseded reference sets, kept for traceability
```

**Privacy rule:** never place original personal reference photographs
here — only approved, original animated character artwork. See
`docs/07_DEVELOPMENT_PLAN.md` §23.

Populated with Melissa and Bilsan in Milestone 5 (seed data).
